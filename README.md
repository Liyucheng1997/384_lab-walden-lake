# 瓦尔登湖 · 林中生活

根据梭罗《瓦尔登湖》（1854）制作的 Three.js 慢节奏休闲游戏。一八四五年七月四日，你搬进了湖畔亲手搭起的小屋——这里没有任务，也没有失败。

## 运行

```bash
npm install
npm run dev
```

然后在浏览器打开终端里显示的地址（默认 http://localhost:5173）。`npm run build` 可打包到 `dist/`。

## 玩法

| 按键 | 作用 |
| --- | --- |
| WASD / 鼠标 | 漫步、环顾（点击画面锁定鼠标；也可按住鼠标拖动） |
| E | 互动：锄豆、垂钓、拾柴、劈柴、生火、读书、就寝、观察动物、聆听…… |
| Q | 测量湖深（在船上或冰面上），结果记在测绘图上 |
| C | 静坐，时间加快，看光阴流过 |
| F / 1–8 | 取出长笛吹奏；不按键时笛声会自己即兴 |
| J / M / H | 日记 · 湖区测绘图 · 帮助 |

- 一天约 12 分钟；在床上可以睡到明早、十天之后或下一个季节。
- 四季：夏日豆田与萤火虫，秋天的红叶与潜鸟，冬天封冻的湖面（可以在冰上凿洞垂钓、测深），春天的解冻。
- 日记共收录劳作、见闻、四季等数十则条目，另有 14 篇手记与 6 种鱼，随经历逐步解锁。
- 进度自动保存在浏览器本地。

所有模型、天空、水面、音效（风、水、鸟、蛙、潜鸟、汽笛、长笛）都是程序生成的，没有外部素材。文中引文据《瓦尔登湖》英文原著（公有领域）自行译写。
